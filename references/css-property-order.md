# CSS Property Order

Ordem recomendada para organizar propriedades dentro de cada seletor.

## 1. Positioning

`position`, `inset`, `top`, `right`, `bottom`, `left`, `z-index`

## 2. Layout

`display`, `flex-*`, `grid-*`, `align-*`, `justify-*`, `gap`

## 3. Box Model

`width`, `min-width`, `max-width`, `height`, `min-height`, `max-height`,
`margin`, `padding`

## 4. Visual

`background`, `border`, `border-radius`, `box-shadow`

## 5. Typography

`color`, `font-*`, `line-height`, `letter-spacing`, `text-*`

## 6. Behavior / Misc

`overflow`, `object-fit`, `cursor`, `pointer-events`

## 7. Animation

`opacity`, `transform`, `transition`, `animation`
